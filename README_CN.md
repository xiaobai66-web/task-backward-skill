## 问题是啥

用AI的时候经常遇到：

- 🚨 **AI抢答** — 你刚说一句"我想买股票"，它就开始推荐股票了，但你其实是想先学习
- 🤷 **理解不对等** — 同一句话有好几种意思，AI只选一种就开始干，也不告诉你为啥
- ❓ **只有结论没有原因** — AI告诉你"要做市场调研"，但不告诉你为啥重要、不做会怎样
- 📄 **给个死流程就完事** — 给你一个固定清单，你补充新信息它也不会调整

这个Skill就是用来解决这些的。

---

## 它做啥

你说个模糊的目标（比如"我想摆个摊"），它会：

1. **列几个可能的理解**（你是想学怎么摆摊？还是已经决定了要帮你选品？还是想知道合不合法？）
2. **问你一个关键问题**，确认你到底想干啥
3. **形成"暂定目标"**，后面可以改（不强迫你一次性说清楚）
4. **往回推关键因素**（摆摊需要考虑：选品、客户、地点、成本...），每个都解释：
   - 这是啥
   - 为啥重要
   - 怎么影响你的目标
   - 举个例子
   - 啥时候可以不管它
5. **生成动态任务图**，你补充信息它会跟着调整
6. **防止跑偏** — 时刻检查现在在哪一步，别聊着聊着就变成上课了

## 例子："我想买股票"

### 没有这个Skill

```
用户：我想买股票
AI：这里有5只很好的股票推荐...
```
❌ AI直接假设你要推荐。但也许你是想先学。

### 有这个Skill

```
用户：我想买股票

AI：我看到几种可能：
A. 从零学习（搞懂股票是啥）
B. 要推荐（具体买哪只）
C. 判断时机（现在适不适合买）
D. 学怎么操作（开户、下单）
E. 小额验证（拿少量钱试试）

最关键的分歧是：你是从零开始，还是已经懂了想直接行动？

你更接近哪个？

用户：我想先学，建立自己的判断，然后拿少量钱验证

AI：明白了。我来倒推一下"学习 → 建立判断 → 验证"需要考虑的关键因素...

关键因素1：股票知识基础
- 是啥：基本概念（市盈率、分红、市值）
- 为啥重要：不懂这些你看不懂财报
- 怎么影响：决定你能不能判断"好公司"
- 例子：好公司 ≠ 当前价格值得买
- 啥时候不重要：如果你只想跟着别人买，这些可以不学

...
```

✅ AI先确认你的意图，然后倒推因素，每个都解释清楚。

## 真的有用吗？

### 测试1：股票投资场景
- **输入**："我想买股票"
- **过程**：AI列了5个候选 → 我说想先学再验证 → AI解释"好公司≠当前价格值得买" → 用小测验检查我懂没懂
- **结果**：没有直接推荐股票，确认了真实意图
- **评分**：9.0/10

### 测试2：Agent配置场景
- **输入**："老看到agent教程，以前不屑，现在发现agent也得像公司一样配置规范化"
- **过程**：AI列了4个候选 → 我选A+B → AI倒推5个关键因素（agent运作机制、工作文件夹结构、交接skill设计等）→ 每个都解释
- **结果**：我从"完全不懂"到"理解配置逻辑"，一轮对话搞定
- **评分**：9.66/10

完整案例看 [examples/](examples/)。

## 怎么用

### Codex用户
1. 把 [skills/codex/SKILL.md](skills/codex/SKILL.md) 复制到你的Codex skills目录
2. 重启Codex或重新加载skills
3. 试试："我想搞个副业"

### DeepSeek Harness (Kiro)用户
1. 把 [skills/harness/task-backward.md](skills/harness/task-backward.md) 复制到你的Harness skills目录
2. 重启Harness或重新加载skills
3. 试试："我想学机器学习"

### 啥时候会触发

**会触发：**
- ✅ "我想做个体户"（模糊目标）
- ✅ "我想学机器学习"（需要拆解）
- ✅ "我想买股票"（多种理解 + 高风险）
- ✅ "看到AI生成视频，想搞个工具"（跨领域）

**不会触发：**
- ❌ "几点了？"（简单事实）
- ❌ "帮我写个函数"（明确执行）
- ❌ "继续"（接着聊）

## 优点

1. ✅ **解决真实痛点** — "AI抢答"在实测中真的发生了
2. ✅ **设计完整且验证过** — 10步流程在真实复杂场景测试过
3. ✅ **不是重复造轮子** — GitHub上没有完整做这个的
4. ✅ **适配AI特点** — 保留"未知"字段，不强迫AI装作确定

---

## 缺点和风险

1. ⚠️ **可能太复杂** — 简单问题也可能被拖入10步流程。需要明确触发规则。
2. ⚠️ **理解检查可能打断流程** — 只在引入新概念或高风险误解时检查
3. ⚠️ **依赖LLM能力** — 候选意图可能不全，概率分数可能不准
4. ⚠️ **演示视频 vs 实际功能** — 视频展示的是理想状态，实际用可能有错
